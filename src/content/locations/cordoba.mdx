## Contexto local

Córdoba no se rehabilita con el catálogo de un clima atlántico. El patio es una máquina de sombra y de bajantes; el casco limita la imagen. El ensanche permite sistemas más contemporáneos si el soporte aguanta.

Esta web informa y conecta con profesionales, no pica fachadas.

El parque se describe aquí como patios, cal y bloques de ensanche, bajo un clima verano extremo. El hilo de esta landing es sombra, patios y morteros. El casco y la Judería tienen criterios de fachada más estrictos que el ensanche.
